Chào mừng bạn đến với website của tôi

Đây là trang chủ trong dự án môn Thiết kế và Quản Lí Web. Tôi dùng trang này để thực hành HTML ngữ nghĩa và CSS.

Bạn có thể xem trang About để biết thêm về tôi, hoặc trang Contact nếu muốn liên hệ.

Tôi đã học được gì

  • Dùng thẻ HTML ngữ nghĩa để chia các vùng của trang
  • Tách giao diện ra file CSS riêng
  • Chia bố cục hai cột bằng flexbox
